# 📘 Exercícios: Entendendo Algoritmos

Este repositório foi criado para documentar e organizar a minha jornada de aprendizado com o livro **"Entendendo Algoritmos: Um Guia Ilustrado para Programadores e Outros Curiosos"**, escrito por Aditya Y. Bhargava. 

O objetivo principal é praticar a lógica de programação, compreender estruturas de dados fundamentais e aprimorar a eficiência dos códigos através do estudo de complexidade de tempo e espaço (Notação Big O).

---

## 🚀 Tecnologias Utilizadas

* **Linguagem principal:** Python 3.x *(Ajuste aqui caso use outra linguagem, como JavaScript, Java, C++, etc.)*
* **Ambiente de execução:** Terminal / VS Code
